# SignageHub 安全与运行边界

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2

员工身份使用BCrypt12和30分钟服务端会话；每次业务操作核对当前账号、密码指纹、角色与组织范围。后台写接口有CSRF，登录更换会话ID，登录失败有每进程限次；没有默认Spring共享账号密码。没有MFA、企业SSO或多实例集中会话/分布式限流。

设备令牌为32随机字节，仅在创建/轮换时显示一次，数据库仅存SHA-256摘要。设备与员工权限独立，令牌不能放在查询参数、浏览器存储、截图或日志。设备API只提供已经投放给该屏幕的文件。禁用屏幕或组织、轮换令牌在联网请求时生效。

PNG/JPEG在读取尺寸后重编码；MP4由ffprobe验证H.264/AAC、尺寸和时长。文件64MB、组织512MB、屏幕节目256MB；只以服务端随机文件名落盘，没有远程文件抓取、路径输入、HTML/SVG网页素材或转码执行脚本。受保护下载有nosniff；排期与发布服务使用参数绑定查询及组织写锁。

播放器只监听127.0.0.1，拒绝未知Host和跨站写请求。播放内容通过DOM文本或媒体元素呈现，不执行CMS提供的HTML。CMS必须使用HTTPS根地址；localhost开发例外明确限定。媒体地址固定为所选CMS的相对路径，不跟随HTTP重定向。

缓存完整校验后原子激活，私有目录0700、配置/状态0600，文件路径由已校验的SHA生成。离线租期有上限，缓存被破坏或时间明显倒退时停止；本机管理员仍能控制设备文件和时钟，这不是防篡改DRM。离线设备无法立即接收撤销，最迟在租期到期停止，重新联网的失效设备清除播放授权。

公网部署需要HTTPS、Secure Cookie、访问控制、防火墙、磁盘/请求配额、日志与备份监控。数据库和播放器设置端口不向公网开放。密钥与.env由部署者独立保管，不放Git；备份含账号/设备摘要与业务素材，仍是私有资料。恢复仅用于可信归档、新空项目和独立本机端口，禁止从未知来源执行SQL备份。

本版尚未做渗透认证、生产负载/高可用、电视硬件、电源/HDMI、真实OS登录自启、Android原生播放及实体Windows/Linux设备认证。安全问题请通过官网联系知华科技，提供脱敏步骤，勿在公开Issue贴凭据或客户资料。
