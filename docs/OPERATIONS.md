# SignageHub 操作手册

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2

管理员用私有.env的初始化信息登录，先维护组织和岗位，再建立员工账号。内容编辑具有素材和节目权限；门店发布还具有屏幕、发布、概况和审计权限；观察岗位只查看运行概况。账号、角色、菜单和系统参数管理需要全部组织范围。权限修改在后续请求实时检查，重置密码或停用账号撤销旧会话。

1. 在素材库选择组织、名称和文件。图片由服务器重新编码；MP4通过编码、尺寸和时长检查。上传后预览实际内容。停用素材只阻止新发布，已有快照保留。
2. 新建节目，选择组织与内容类别，填写中英文名称、画布方向、背景和适配。添加媒体或纯文本项目、显示秒数及文字颜色，按顺序调整并保存。版本冲突时刷新核对，不覆盖他人的修改。
3. 添加屏幕、选择分组。保存一次性设备令牌；配置页面关闭后不能找回原文。需要重新配对时生成新令牌，旧联网客户端立即失效。避免把令牌放入截图或网址。
4. 在播放电脑运行`node player/src/launcher.js`，使用明确的`PLAYER_DATA_DIR`或在player目录运行以保持缓存路径稳定。本机设置页输入HTTPS后台根地址与设备令牌；同机调试可用localhost。打开`/display`，按全屏按钮进入全屏。
5. 在发布与排期中选择草稿、屏幕/分组，立即发布或设置起止时间。界面时间输入为浏览器本地时区；服务端转换到UTC。一次发布冻结当时的屏幕名单，不把以后加入分组的屏幕悄悄追加进去。
6. 播放器下载并验证全部素材后切换。未来七天排期随节目缓存；到期自动恢复常驻节目。撤销排期在下次联网同步后生效。常驻回滚只能选择该屏幕以前收到过的版本，不能借回滚获取其他屏幕的内容。
7. 运行概况区分目标、已播放、连接与错误。最近两分钟有回报视为在线；PLAYING必须来自本机渲染器确认，缓存完成本身不是播放证据。CSV遵守组织权限且处理公式前缀。

断网时，本机播放器服务须持续运行，浏览器从本机取得缓存文件；内容后台暂不可达不会强制切换到未下载的节目。租期最多72小时，过期停止；本机时间明显回退、缓存损坏和播放器服务停止均给出错误。无法在断网时立即撤销已授权内容，这是有限离线播放的边界。

播放器进程守护负责重启自身子进程。操作系统登录启动文件由`player-service.py`生成，须在目标电脑由操作员安装；浏览器无人值守启动及全屏策略需要按设备环境配置和验收。视频默认静音，不把操作系统启动文件当作已完成电视电源或浏览器自启的证明。

原始素材文件、数据库、私有.env和设备配对配置应独立备份。SQL与媒体必须来自同一暂停写入期间；官方备份脚本连接两者。不要在数据库卷中手动删表、重写迁移或修改已有发布快照。
